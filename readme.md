
# Team Fortress 2 Guessing Game

A **HUMAN-MADE website** made by my friend **DooDooDeeDee**.

It's about TF2 maps. yup.

[**Play it on GitHub Pages**](https://uh-oh-man.github.io/Doo-TF2-Guessing-game/)

## What's on the website?

There are 3 main sections:

### 1. Map Information

A bunch of probably unnecessary information about TF2 maps.

-   Map counts, gamemodes, and release dates.
    
-   Halloween and Christmas maps.
    
-   Maps that reuse the same layouts.
    
-   Valve-made and community-made maps.
    
-   Which maps are available in Casual.
    

### 2. Map Guessing Game

Look at a picture of a TF2 map and figure out what it is.

-   Guess the name, file name, gamemode, and release date.
    
-   Earn points with up to 8 guesses per map.
    
-   Switch between typing and dropdown answers.
    
-   Change which maps appear using various settings.
    

### 3. Extra TF2 Files

Some optional files you can download, including:

-   Missing map files.
    
-   Bot navigation files.
    
-   Additional Pyrovision support.
    
-   Simplified server browser improvements.
